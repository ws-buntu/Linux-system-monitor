# Linux System Health & Security Monitor

A Python automation tool that collects system health metrics and basic security indicators on Linux systems.

## Features

- CPU, memory, disk monitoring
- Logged-in user tracking
- Failed login detection
- Suspicious process listing
- Timestamped security reports

## Use Cases

- SOC entry-level tooling
- Linux administration
- Security automation labs
- SME infrastructure monitoring

## Tech Stack

- Python 3
- Linux (Ubuntu / Kali)
- Bash utilities

## How to Run

```bash
python3 monitor.py
